This is a beta, and it behaves like one.

It matches against every photograph the house holds of a catalog item — the whole photo file — including photographs that are not published. Matching is internal computation; the results show an item's published photograph where it has one, and no photograph where it hasn't.

Similar-looking figures will confuse it. A match is a suggestion to check, not a determination.

Results improve as the photo file grows. Every photograph added to the file sharpens the next search.
